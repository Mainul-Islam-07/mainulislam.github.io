Developed a simplified educational computer model to demonstrate architecture concepts. 

Its customized with less T-states.

Features an ALU, control unit, registers for temporary data storage, limited memory for instructions and data, input/output devices, a clock for timing, and executes instructions through fetch-decode-execute cycles etc.

Basic instructions like addition and subtraction, etc
