System Architecture

Subsystem Highlights

🛰 Localization EKF

  • 5-state EKF fusing wheel odometry with AprilTag pose, predicting at 50 Hz.
  • Online velocity-bias estimation — encoders treated as biased sensors.
  • Joseph-form covariance + midpoint integration for numerical stability.
  • OOSM rewind/replay correctly fuses latency-delayed camera frames.

🗺 Planning A*

  • Space-time A* over (cell, heading, time) with turn-minimizing cost.
  • Reservation table resolves vertex, edge-swap & parked-robot conflicts.
  • Stateless planner service vs. stateful plan-manager orchestrator.
  • Continuous ETA re-timing keeps every robot's schedule honest.

🎮 Control 50 Hz

  • Feedforward + PD trajectory tracking in the robot body frame.
  • Cubic-Bézier waypoint interpolation with smart heading logic.
  • Differential-drive mixing on the real 355 mm wheelbase.
  • Immediate collision / FAILSAFE / idle stop interlocks.

🏭 Fleet Orchestration FSM

  • 3 concurrent FSMs over a shared FIFO job queue (~20 states each).
  • Atomic mutual exclusion on lift/scanner with staging queues.
  • Publish-until-accept delivery; transition-counter accept/arrival.
  • Deadlock & stuck detection → staggered fallback recovery.

🛡 Reliability Health

  • INIT→READY↔FAILSAFE startup guard gated on fleet + peer liveness.
  • Heartbeat → directory → guard chain with anti-cascade margins.
  • Chrony NTP monitoring with automatic soft/hard resync.
  • Hysteresis on all mode transitions to reject transient dropouts.

⚙ Hardware Integration Embedded

  • Modbus RTU servo drives @ 115200 baud on Raspberry Pi 5.
  • 17-bit encoders (131,072 CPR) with 32-bit wrap-safe odometry.
  • LiDAR safety zone with rotation-aware false-stop suppression.
  • Deadman timeout + Modbus write de-duplication throughout.
