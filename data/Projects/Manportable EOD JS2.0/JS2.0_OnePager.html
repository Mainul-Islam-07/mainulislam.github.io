Overview

An operator drives a tracked robot and its 7-DOF manipulator arm from a handheld console — over wireless RF or a redundant wired serial-over-Ethernet link (intended for optical fiber) — to remotely inspect and neutralize suspect ordnance, with live multi-camera video, a 3D digital twin, real-time motor telemetry, two-way audio, and remote disrupter fire-control. Onboard a Raspberry Pi 5, a ROS 2 graph translates RC commands into coordinated motion across two CAN buses of servo drives via a custom CANopen stack, using a closed-form IK solver with MoveIt 2 for collision-validity and home planning. Because the platform carries a disrupter, fail-safe behavior was a first-class design constraint.

What I Built

  • Redundant control link (dual STM32 firmware) — STM32F103 firmware that transparently tunnels the raw SBUS RC stream over a WIZnet-W5500 UDP link, with a hardware watchdog that fails over to a wireless backup if the wired path goes silent.
  • Custom CANopen (CiA-402) control stack — a library on python-canopen driving 11 servo drives on two 1 Mbit/s CAN buses in position / velocity / torque modes, with 50 Hz SDO setpoints and interrupt-driven TPDO telemetry.
  • Closed-form inverse kinematics + selective MoveIt 2 — an analytic solver for the telescoping arm (2R shoulder/elbow + additive wrist-pitch; six of the seven DOF integrated), verified against the URDF; MoveIt handles collision-validity and the home pose, not the operator's real-time path.
  • Layered fault-tolerance & fail-safe system — asymmetric per-bus fault isolation with full-disarm, latched safe states, a loopback degraded mode when motors drop out, and an encoder-battery startup gate.
  • Fail-safe remote disrupter fire-control — bounded-hold firing over TCP with an operator-presence heartbeat that disarms the instant the ground-station link is lost.
  • Android operator console — 5-feed low-latency RTSP switching (hardware MediaCodec), a Compose telemetry dashboard, a 3D digital-twin OpenGL overlay, echo-cancelled intercom, gimbal control, and the fire-control UI.

Engineering Depth

  • Embedded firmware: UART-DMA idle-line framing at the SBUS line rate (100k, 8E2); interrupt-driven W5500 sockets (EXTI deferred-flag pattern); PHY-loss socket recovery; a TIM1 watchdog that drives GPIO relays to a wireless backup on wired-link loss.
  • Real-time control: 50 Hz cyclic SDO setpoints with asynchronous TPDO telemetry; software drivetrain modeling — differential shoulder/elbow pair, lead-screw telescope, worm-gear flippers.
  • Safety architecture: drive-bus fault → disarm both buses + safe shutdown; arm-bus heartbeat loss → latched arm safe state while the base runs; firing defaults to not armed on link loss.
  • Kinematics & coordination: analytic 2R + additive-pitch IK verified vs the URDF; a single-consumer/multi-producer coordinator (4-thread executor) with goal rollback and a re-arm anti-thrash guard.
